# Demo script

Under 90 seconds. One chat, one wave. Do not narrate a longer bit than the line below.

On Hermes Desktop, leave the web dashboard closed. Send `25c`. Top Sails opens over the window. Press Esc and it is gone.

## Setup before the take

1. Install and enable the plugin (see the README). Restart `hermes dashboard`.
2. Open the dashboard chat. Leave the cabinet tab closed so the popup is the surprise.
3. Click the chat composer so the first keystrokes land there.
4. Optional rehearsal without Hermes: serve this repo and open `/preview/`. That is the same cabinet, but it will not show the chat trigger. Use it to practice the first wave, then record the Hermes path.

## The take

| Time | Do this | What should be on screen |
| --- | --- | --- |
| 0:00 | Dashboard chat, composer focused. | Normal Hermes chat. No cabinet yet. |
| 0:08 | Type `25c` and send. Nothing else in the message. | The composer shows only `25c`. |
| 0:12 | Wait. | The assistant line is exactly: Thought we wouldn't notice. But we did. A cabinet pops over the page. Marquee: TOP SAILS. Screen: CREDIT 1, then bugs. |
| 0:20 | Click the screen if it does not already have focus. Hold Right (or D) and Space. Sweep the mint bugs. | Player ship at the bottom fires upward. Score ticks. Wave 1 is short. |
| 0:45 | Keep firing until the row is gone. | WAVE 2 appears. Stop there if the take is tight. |
| 0:55 | Tap M once if you want the tones off. | The button reads SOUND OFF. |
| 1:05 | Press Esc, or BACK. | The cabinet closes. Chat is still there, with the one-line reply. |

If the popup does not appear, open the **Thought We Wouldn't Notice** tab and press **Play Top Sails**. Same game, on that page, under the banner. The chat line should still have replaced a model reply.

Backup trigger, if you need a second take and do not want to type the coin again: send `/quarter`. It writes the same drop and the same line, and it never goes to the model.
