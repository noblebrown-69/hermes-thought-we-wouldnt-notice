# Thought We Wouldn't Notice

Restart the dashboard after enabling this plugin.

Open a chat and send a message that is only a quarter, for example `25c`.
The reply is one line, and the cabinet pops over the dashboard.

In Hermes Desktop, send `25c` with the web dashboard closed. Top Sails opens over the window. Esc closes it.

The **Thought We Wouldn't Notice** tab has the banner, a short note, and **Play Top Sails** on the same page. The game on that cabinet is Top Sails.
Status: `hermes thought-we-wouldnt-notice status`
